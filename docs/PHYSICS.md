# 物理效果與狀態機

v0.1.0 包含以下動畫、狀態轉移與物理效果。可從 Release 下載 Windows 版本，或用原始碼開發預覽。

2026-11-05：96 項自動測試通過，涵蓋物理、睡眠／喚醒、選單避讓、新版動畫、連續移動與更新功能。
原生全螢幕切換測試需讓測試視窗取得前景，避免誤把其他全螢幕程式當作測試成功。

## 體驗方式

```powershell
.\.venv\Scripts\python.exe src\main.py --data-dir local-data-physics-preview --dev-actions
```

啟動時打招呼；開發預覽加上 `--dev-actions` 後，右鍵「動作」可直接試播打招呼、側躺／起身與跳躍。
背景預覽腳本會自動帶入這個參數。發布版不提供選擇動作的選單，仍保留自主行為。
若需要從空中落下的示範，可加上 `--demo-drop`。拖曳時關閉重力、清除原速度；放開後，水平與垂直速度
都歸零，再受重力垂直落下。滑鼠移動速度不會轉換成角色速度。

地板是目前螢幕工作區底部，左右與上方也是工作區邊界。飛行留在目前螢幕，
拖曳可換螢幕。碰撞範圍為完整 sprite 畫格，無旋轉或形變。
被放下時的空中動畫使用 Drag，落地使用 Idle。主動跳躍使用專用左右動畫。

## 模組分工

- `core/state_machine.py`：通用狀態機，提供 `enter`、`exit`、`update`、`handle`。
- `core/behavior.py`：每個狀態各有自己的類別，只產生動畫名稱與行走速度意圖。
- `core/physics.py`：唯一負責位置與速度，處理重力、支撐、碰撞衝量與摩擦。
- `core/controller.py`：將滑鼠、模式與物理接觸轉為事件，協調計時及視窗顯示。

| 狀態 | 事件或時間結束後的轉移 |
| --- | --- |
| Idle | 停留後 → Walk；每第三段移動改成 Jump；完成四段移動後 → LieDown |
| Walk | 共用活動時間結束後計為一次移動 → Idle；碰牆 → 反向 |
| Wave | 啟動、點擊或睡醒觸發，完整播一次 → Idle；重複點擊不會重播開頭 |
| Jump | 每次落地後重新檢查時間與空間並接下一跳，整段結束計為一次移動 → Idle |
| LieDown | 播完躺下過渡 → Lie；若收到起身要求，先完成躺下再 GetUp |
| Lie | 側躺 6 秒 → GetUp；點擊則排定 GetUp → Wave |
| GetUp | 完整播完起身過渡 → Idle 或排定的動作；有睡眠要求時 → Sleep |
| Sleep | 持續睡眠，新輸入 → Wave → Idle；手動專注期間保持睡眠 |
| Drag | 放手 → Fall |
| Fall | 最後一次反彈結束、得到地面支撐 → Land |
| Land | 停留 0.3 秒 → Idle；若有睡眠要求則 → Sleep |

地面狀態可被點擊、抓起、離地與睡眠要求中斷。Fall 可隨時被抓起，
但不會因為使用者閒置或手動專注而在空中進入睡眠。落地前所有反彈都維持 Fall。
切換隱藏、穿透、專注或設定時若取消拖曳，釋放速度為零。
暫停期間仍可拖曳，恢復更新才開始自由落下。

動作種類依互動、移動次數與睡眠需求決定；僅停留時間及一般步行方向保留少量隨機。
Walk 與 Jump 共用 `MovementState` 的活動時間預算，依素材完整跳躍時間的三倍計算；
目前單跳 1.03 秒，故每段約 3.09 秒。走路依經過時間扣除預算；跳躍每次完整落地後扣除該動畫時間，
正常連跳三次，避免計時誤差導致多跳或在空中切斷。整段連跳只計為一次移動。
每次接下一跳前，都從落地後的位置重新驗證完整路徑；必要時轉向，兩邊都不足時提前停止。
點擊或睡眠要求會在當次落地後處理，不再接下一跳；拖曳則立即中斷。
完成四次移動就安排一次側躺，進入側躺後清除這個計數；每第三次移動的計數持續累積。
Win32 每秒回報鍵鼠閒置時間，
滿 60 秒送出 `SLEEP_REQUESTED`；有新輸入送出 `WAKE`。Sleep 沒有自動離開的計時器。
兔兔的點擊、拖曳與右鍵操作會立即回報輸入，不必等待下一次 OS 輪詢。
手動專注仍會要求睡眠及穿透，但不再依使用者閒置時間自動進入專注模式。
若睡眠要求出現在跳躍中，會先完成落地；若正在側躺，會先起身再播放 Sleep。
拖曳優先權最高，可以中斷這些動作；放手仍只垂直落下，不恢復拋擲。

## 新素材的尺寸與位移

使用 manifest v3 的每動畫尺寸、錨點、逐格時間、循環旗標及下一段動畫資訊。
一次性動畫送出 `ANIMATION_FINISHED`，由狀態機決定下一個狀態，不以近似秒數硬切。

75% 大小時，站立為 144×198、打招呼為 168×198、跳躍為 144×258、
躺下／起身為 216×216、側躺為 216×120 邏輯像素。
切換時保存腳底錨點，以新錨點反算視窗左上角；靠邊時僅做必要修正，避免畫面超出工作區。
縮放會保留當前影格與播放進度。拖曳期間尺寸變化會重算滑鼠抓取偏移，避免瞬移。

跳躍的上下弧線已畫在 sprite 裡，不再施加額外起跳重力。
`frame_offsets_px` 視為進入每格時的增量，左右跳躍合計移動 ±88 原始像素，
75% 大小時為 ±66 邏輯像素；略過影格仍會累加所有位移事件。
開始前確認整段路徑有足夠空間，必要時改朝另一邊；兩邊都不足時不安排跳躍。
若跳到一半被抓起，依當格的可見腳底高度接回自由落體，避免突然落到地板。

右鍵選單以完整 sprite 畫格避讓，優先右側、其次左側，窄螢幕可改放上方或下方。
選單開啟期間凍結角色更新，並暫停桌寵原生置頂重排；關閉後依原本暫停／隱藏設定恢復。

新增狀態時，在 `State` 加入識別值，建立繼承 `BehaviorState` 或 `GroundState`
的類別，再註冊到 `STATE_TYPES`。時間結束行為可繼承 `TimedGroundState`。
狀態類別可覆寫動畫與行走意圖，避免直接改視窗座標。需要的新輸入事件加到 `Event`，
並由對應狀態處理。新增素材也要在 manifest 註冊動畫。

## 參數與計時

`PhysicsSettings` 的單位是 Qt 邏輯像素及秒；參數集中在 `core/physics.py`：

| 參數 | 預設 | 效果 |
| --- | --- | --- |
| gravity | 1800 px/s² | 落下加速度 |
| restitution | 0.32 | 地面反彈後的速度比例 |
| wall_restitution | 0.45 | 牆面／天花板碰撞後的速度比例 |
| minimum_bounce_speed | 85 px/s | 小於此反彈速度時直接停止，避免顫動 |
| ground_friction | 1100 px/s² | 落地滑行減速 |
| walk_acceleration | 650 px/s² | 自主行走的加速度 |
| air_drag | 0.25 /s | 空中水平阻力 |

視窗約 30 Hz 更新，物理以 1/120 秒固定步長補算；循環動畫取樣為 8–12 Hz，
一次性動畫每次邏輯更新都推進，沿用 manifest 的逐格時長。單次卡頓最多補算 0.1 秒；暫停及隱藏會停止計時器，
恢復時重設時間基準，不把背景等待時間累積成一次大位移。

螢幕工作區或角色大小改變時，位置重新限制並清除速度；若因此接觸地板，
會發出落地事件，避免狀態停在 Fall。此版本尚未與其他應用程式視窗碰撞。
